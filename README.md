# Spotify Analytics — encore

**encore** is a deeper, prettier yearly music recap built from your Spotify Extended Streaming History.
It has a tap-through story, a dashboard of more than 25 metrics, and an AI Metric Lab where you can describe your own stats.
Everything runs in the browser, so your listening data is never uploaded.

The app lives in [`wrapped/`](wrapped/). See [wrapped/README.md](wrapped/README.md) for features, local development and Vercel deployment.
On Vercel, set **Root Directory** to `wrapped`.
